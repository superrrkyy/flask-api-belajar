# Kebijakan Keamanan

Terima kasih sudah membantu menjaga keamanan proyek ini. 🔐

## Versi yang Didukung

Perbaikan keamanan diberikan untuk versi terbaru di branch `main`.

| Versi | Didukung |
| ----- | -------- |
| Terbaru (main) | ✅ |
| Rilis lama | ❌ |

## Melaporkan Kerentanan

**Jangan** membuka issue publik untuk masalah keamanan.

1. Gunakan tab **Security → Report a vulnerability** di repo ini (disarankan), **atau**
2. Kirim surel ke pemilik repo melalui kontak di profil GitHub.

Sertakan bila memungkinkan:
- Deskripsi masalah & dampaknya
- Langkah reproduksi (versi, perintah, contoh request)
- Bukti konsep (PoC) secukupnya
- Saran perbaikan bila ada

## Yang Kami Janjikan

| Tahap | Target waktu |
| ----- | ------------ |
| Konfirmasi laporan diterima | ≤ 3 hari |
| Penilaian awal & rencana perbaikan | ≤ 7 hari |
| Perbaikan dirilis | ≤ 30 hari (tergantung tingkat keparahan) |

Pelapor akan dicantumkan namanya di catatan rilis bila mengizinkan.

## Di Luar Cakupan

- Kerentanan pada layanan pihak ketiga (GitHub, CoinGecko, AniList, Audius, iTunes, Open-Meteo, YouTube)
- Serangan yang memerlukan akses fisik ke perangkat korban
- Hasil pemindaian otomatis tanpa bukti dampak nyata
